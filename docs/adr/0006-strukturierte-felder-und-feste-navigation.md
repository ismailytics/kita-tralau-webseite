# Strukturierte Felder pro Seitentyp, feste Navigation

Alle Inhalte liegen in Storyblok, aber jede Seite hat feste, strukturierte Felder statt eines freien Seitenbaukastens. So kann die Redaktion das Layout nicht versehentlich zerstören, und der Support bleibt klein. Die Navigation ist im Code fest verdrahtet, weil sich der Seitensatz einer Kita kaum ändert. Eine neue Seite ist dann eine seltene Codeänderung, keine Redaktionsaufgabe. Bewusst nicht enthalten sind Newsletter und eine Team-Seite der Kita.
