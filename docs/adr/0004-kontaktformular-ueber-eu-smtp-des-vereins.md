# Kontaktformular über EU-SMTP des Vereins, kein Mail-API-Dienst

Kontaktanfragen werden per SMTP über das Postfach des Vereins bei seinem EU-Hoster verschickt. Ein Mail-API-Dienst wie Resend war die Alternative. Wir verzichten darauf: Ziel ist ohnehin das eigene Postfach, ein US-Subprozessor fiele weg, und die Datenschutzerklärung wird kürzer. Lokal wird gegen Mailpit entwickelt.
