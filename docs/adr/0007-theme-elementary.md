# Theme Elementary als Basis

Wir bauen auf dem Astro-Theme Elementary auf (MIT, Tailwind v4, kita-spezifisches Design) und entkernen es (Newsletter, Enrollment, Teachers, Testimonials raus). Teuer ist das kita-gerechte Design. Die Anbindung an Storyblok ist bei jedem Theme gleich aufwendig, deshalb wird das Theme nicht gewechselt.
