# Hosting nur mit EU-Laufzeit

Die Site läuft ausschließlich bei einem EU-Hoster. Infrage kommen IONOS Deploy Now (managed) oder ALL-INKL mit Deploy per GitHub Action. Welcher, entscheidet der Vorstand. Beide sind Apache mit `.htaccess` ohne Node-Laufzeit, die Site muss also rein statisch plus ggf. PHP funktionieren.

## Considered Options

- Vercel: Der Hobby-Plan ist nur für „non-commercial personal use“, für einen Verein unklar.
- Netlify: US-Hoster.
- Cloudflare Pages: EU-Datenhaltung nur mit Enterprise, kein SMTP.
